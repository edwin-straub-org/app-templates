# Application Templates

This repository contains application templates for the platform.

## Available Templates

### basic-app

A basic Go application with:
- Sample HTTP server
- Dockerfile
- CI/CD pipeline configuration
- Platform claim integration

## Usage

1. Copy a template directory
2. Modify the application code
3. Push to your repository
4. CI/CD will automatically deploy to configured stages

## Platform Features

Applications can request platform features in their claim:

- postgres: PostgreSQL database
- rabbitmq: RabbitMQ messaging
- monitoring: Prometheus monitoring

Example claim will be generated by CI/CD pipeline.
